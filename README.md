# 🌗 FXTimeWeather

**Показ фази доби, погоди та ігрового часу у боссбарі чи actionbar**
**з підтримкою кастомних плейсхолдерів для PlaceholderAPI**

Ядро: `Paper` · Версія: `[ 1.21.1–1.21.11 ]` · Java: `21`

</div>

## 📖 Про плагін

FXTimeWeather відстежує стан кожного світу на сервері — фазу доби, погоду,
номер ігрового дня та поточний ігровий час — і показує це гравцям через
**боссбар або actionbar** (на вибір), а також надає ці дані іншим плагінам
через плейсхолдери PlaceholderAPI (табам, скорбордам, менюшкам тощо).

## ✨ Можливості

|    |                                                                                      |
|----|--------------------------------------------------------------------------------------|
| 🌗 | Визначення фази доби (Світанок, Ранок, День, Вечір, Сутінки, Ніч) за ігровими тіками |
| 🌦 | Визначення погоди (Ясно, Дощ, Гроза) у кожному світі окремо                          |
| 📊 | Режим боссбару — кастомний колір, стиль та текст                                     |
| 💬 | Режим actionbar — окремий текст та інтервал оновлення                                |
| 🔀 | Один перемикач `display.type` у конфізі — боссбар **або** actionbar                  |
| 🔢 | Лічильник ігрового дня світу                                                         |
| 🕐 | Ігровий час у форматі `HH:mm` (або `HH:mm:ss`)                                       |
| 🔌 | Плейсхолдери PlaceholderAPI (`%fxtw_...%`)                                           |
| 👤 | Персональне вмикання/вимикання показу для кожного гравця (`/twtoggle`)               |
| 💾 | Стан `/twtoggle` зберігається між заходами на сервер                                 |
| 🎨 | Підтримка hex-градієнтів у текстах (`<#HEX1>текст</#HEX2>`)                          |
| ⚙️ | Повністю конфігуровані тексти, кольори та іконки                                     |

## 📥 Встановлення

1. Завантажте `FXTimeWeather-1.0.jar`
2. Помістіть його у папку `plugins/` вашого сервера
3. *(Опційно)* встановіть [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) для роботи плейсхолдерів у інших плагінах
4. Перезапустіть сервер
5. Налаштуйте `plugins/FXTimeWeather/config.yml` під себе

## 🎮 Команди

| Команда     | Опис                                      | Право         |
|-------------|-------------------------------------------|---------------|
| `/twreload` | Перезавантажити конфігурацію плагіну      | `fxtw.reload` |
| `/twtoggle` | Увімкнути/вимкнути показ інфо-панелі собі | `fxtw.use`    |

## 🔑 Права

| Право         | Опис                                                             | За замовчуванням    |
|---------------|------------------------------------------------------------------|---------------------|
| `fxtw.reload` | Дозволяє використовувати `/twreload`                             | `op`                |
| `fxtw.use`    | Дозволяє використовувати `/twtoggle` та бачити боссбар/actionbar | `true` (усі гравці) |

## 👤 Персональне вимикання (`/twtoggle`)

- Кожен гравець може особисто вимкнути собі показ інфо-панелі командою `/twtoggle`, не впливаючи на інших гравців.
- За замовчуванням (при першому вході) відображення **увімкнене**.
- Стан зберігається у `plugins/FXTimeWeather/players.yml` і не скидається при виході чи перезапуску сервера — плагін пам'ятає вибір кожного гравця назавжди.

## 🖥️ Режим відображення (`display.type`)

У `config.yml` активний **лише один** режим одночасно:

```yaml
display:
  type: bossbar   # або: actionbar
```

- `bossbar` — використовує налаштування з блоку `display.bossbar` (колір, стиль, текст)

та виконуючи `/twreload`.

## 🌈 Градієнти в текстах

Будь-який текст у конфізі (боссбар, actionbar, повідомлення) підтримує
плавний перелив кольору між двома hex-кодами:

```yaml
prefix: "<#8B00F8>FXTɪᴍᴇWᴇᴀᴛʜᴇʀ</#F700FC> &7• &r"
```

Кожен символ між тегами отримує проміжний колір між `#8B00F8` та `#F700FC`.
Стандартні `&`-коди кольору (`&a`, `&c`, `&7` тощо) продовжують працювати поруч.

## 🔡 Плейсхолдери
### PlaceholderAPI (для сторонніх плагінів)

Ідентифікатор: **`fxtw`**

| Плейсхолдер           | Опис                           |
|-----------------------|--------------------------------|
| `%fxtw_time_icon%`    | Іконка поточної фази доби      |
| `%fxtw_time_name%`    | Назва поточної фази доби       |
| `%fxtw_weather_icon%` | Іконка поточної погоди         |
| `%fxtw_weather_name%` | Назва поточної погоди          |
| `%fxtw_day_count%`    | Номер ігрового дня світу       |
| `%fxtw_day_time%`     | Ігровий час (формат з конфігу) |

## 🌅 Фази доби та інтервали тіків

| Фаза     | Інтервал (тіки)   | Стандартна іконка   |
|----------|-------------------|---------------------|
| Світанок | 23000 – 0         | `&7☀`               |
| Ранок    | 0 – 2000          | `&e☀`               |
| День     | 2000 – 11000      | `&6☀`               |
| Вечір    | 11000 – 12000     | `&e🌙`              |
| Сутінки  | 12000 – 13000     | `&7🌙`              |
| Ніч      | 13000 – 23000     | `&8🌙`              |

## ⚙️ Конфігурація

Усі тексти, іконки, кольори та інтервали оновлення повністю редагуються
у `config.yml` — детальні коментарі є прямо у файлі.

## 💾 Файли даних

| Файл          | Призначення                                                        |
|---------------|--------------------------------------------------------------------|
| `config.yml`  | Основні налаштування плагіну                                       |
| `players.yml` | Збережений стан `/twtoggle` для кожного гравця (UUID → true/false) |
